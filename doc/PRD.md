# PRD - WebP: Web Presence na Era da IA

> **Versao:** 1.0 | **Data:** 2026-01-21
> **Repositorio:** https://github.com/inematds/webp

---

## 1. VISAO GERAL

### 1.1 Objetivo
Criar um curso completo sobre Web Presence (WebP) focado em ensinar os **conceitos fundamentais de design web** para que qualquer pessoa possa orientar IAs generativas (vibe coding) a criar exatamente o que deseja.

### 1.2 Publico-Alvo
- Empreendedores que querem criar seus proprios sites
- Profissionais de marketing/comunicacao
- Pessoas interessadas em vibe coding
- Qualquer pessoa que queira usar IAs para criar presenca digital

### 1.3 Diferencial
- **Foco em conceitos, nao ferramentas** - Principios que permanecem
- **Vocabulario para IAs** - Termos que v0, Lovable, Cursor entendem
- **Templates de prompts** - Padroes reutilizaveis
- **Progressao logica** - Do basico ao avancado
